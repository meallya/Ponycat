# Ponycat

**A Multifunctional Desktop Companion for Windows**

Ponycat is a Windows desktop application inspired by the Dynamic Island concept, designed to provide convenient access to everyday tools and utilities through an interactive desktop interface.

## Features

- **Music** – Media controls and song information.
- **Prayer** – Prayer time reminders, Adhan notifications, and Quran recitation.
- **Timer** – Countdown timer functionality.
- **Notifications** – Desktop notification management.
- **Lists & Notes** – Simple task lists and note-taking.
- **Temporary File Drop** – Quick temporary file storage.
- **File Converter** – File and image conversion utilities.
- **App Search** – Search and launch applications installed on Windows.

## Tech Stack

- Electron
- React
- Vite
- Framer Motion
- JavaScript

## Development Status

Ponycat is currently under active development and private testing. Features, performance, and stability are continuously being improved.

Not yet available for public release.
